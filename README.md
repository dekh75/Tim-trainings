# План тренировок Тима

Актуальная мобильная версия годовой программы дополнительной подготовки для юного футболиста: силовая работа, стопа и голень, контроль колена и таза, задняя цепь, корпус, плечи, плиометрика, восстановление, сон и питание.

Публичная страница публикуется через GitHub Pages из `index.html` ветки `main`.
